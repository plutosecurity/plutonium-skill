# Security Policy

## Supported versions

Security fixes are provided for the latest published release of Plutonium Skill.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option in this repository's Security tab so the report and any supporting evidence remain private.

Include the affected release, reproduction steps, expected impact, and any relevant logs with secrets removed. Pluto Security will acknowledge the report and coordinate remediation and disclosure as appropriate.

For incorrect catalog content rather than a software vulnerability, use the **Report a mistake** action on the relevant assessment page at [Plutonium](https://plutonium.pluto.security/).
